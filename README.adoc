Quintessence is a three-layer formal verification suite for Elixir/OTP. It proves
three properties the standard BEAM toolchain does not:

. *Layer A (Sequential subset)* — pure functions satisfy their `@pre`/`@post`
  contracts for *all* valid inputs, terminate along an explicit `@measure`, and
  preserve `secret-types` lattice TINI non-interference.
. *Layer B (OTP / GenServer protocol layer)* — processes claim remote state
  commitment *only* across proved two-party `K-REPLY` causal round-trips
  (`choreographic-types` Y-6/Y-8), never across asynchronous `cast`/`send`,
  under bounded mailbox occupancy and supervision epoch restarts (`k = 12` BMC).
. *Layer C (Native NIF boundary)* — Zig/Rustler NIFs satisfy C1--C12 safety
  obligations, match their reproducible binary SHA-256 receipt at load time, and
  satisfy `MaxPlus <= 1,000 us` for normal BEAM schedulers (or declare
  `schedule: :dirty_cpu`).

[IMPORTANT]
====
*Current implementation state (`v0.1.0-alpha` vertical slice):* The native Zig
compiler/verifier (`src/core/` + `src/interface/ffi/`), dual Z3 5.3.1 + CVC5
1.4.2 SMT & Alethe proof-DAG kernel checker, `k = 12` symbolic BMC engine,
Layer C `MaxPlus` / `dlopen` / SHA-256 receipt verifier, 6-kind ECHIDNA mutation
engine, Elixir Mix frontend (`mix.exs`, `lib/`), and 15-case live regression
suite (`tests/quintessence/run_suite.sh`) *compile and execute today*, producing
honest `TrustLevel 4` local certificates. Batch `coqc` + `lean` `TrustLevel 5`
promotion and `beam_lib` bytecode tracing are scheduled in Milestones M1--M5 of
link:docs/architecture/QUINTESSENCE-IMPLEMENTATION-PLAN.adoc[the Implementation Plan].

== Quick start

[source,bash]
----
just build                                                       # build libquintessence.so + CLI
./src/interface/ffi/zig-out/bin/quintessence doctor              # check Z3, CVC5, Zig, Alethe kernel
./src/interface/ffi/zig-out/bin/quintessence verify examples/quintessence
just test                                                        # 10 Zig unit tests + 15 E2E cases
just validate                                                    # RSR structure, deed, AI guide
----

When Elixir/Mix is installed alongside the native binary:

[source,bash]
----
mix quintessence.doctor
mix verify examples/quintessence --strict
mix quintessence.explain Q-401
----
