== Architectural design of the native engine

=== Why a native Zig core behind thin language bridges

Quintessence deliberately implements Stages 1--10 inside a zero-dependency
compiled Zig library and CLI (`src/core/` + `src/interface/ffi/`) wrapped by a
thin Elixir Mix task layer (`lib/quintessence/`):

. *Estate language policy compliance.* Zig, Elixir, Idris2, Agda, Lean 4, and
  Coq are first-class authorised languages across the estate; no Python,
  TypeScript, Go, or Nix code exists anywhere in the repository.
. *Single source of truth for `qir/v1`, JCS hashing, and exit codes.* Implement-once
  semantics ensure CLI runs, CI SARIF jobs, C-ABI FFI callers, and `mix verify`
  produce bit-for-bit identical `qir_sha256`, `warrant_sha256`, and exit codes.
. *Direct `dlopen` and binary inspection.* Layer C inspects compiled ELF `.so`
  exports and executes linear null-handle probes in-process via POSIX `dlopen`
  without starting a separate runtime.

== Four empirical lessons discovered during live bring-up

Building and running the engine against real solvers exposed four concrete
defects that pure specification review missed. Every future phase must preserve
these invariants:

. *Quantifier E-matching non-termination on SAT witness queries (`V1`/`V2`).*
  Background axioms written with universal quantifiers — notably
  `(forall ((x Int)) (=> (> (list_len x) 0) (= (list_len (tail_of x)) (- (list_len x) 1))))`
  — discharge `unsat` obligations in `< 5 ms`, but cause Z3 model construction
  to diverge on *satisfiable* queries (`V1` antecedent satisfiability and `V2`
  postcondition falsifiability) by instantiating an infinite chain
  `tail_of(tail_of(tail_of(...)))`. Ground-instantiating domain facts onto the
  in-scope terms keeps obligations strictly inside decidable `QF_UFLIA` so both
  `sat` and `unsat` terminate in milliseconds.
. *Eager lexical resolution of pattern binders at recursive call sites.*
  In `def depth(history), do: case history do [] -> 0; [_ | rest] -> 1 + depth(rest) end`,
  recording raw AST arguments on `depth(rest)` and lowering them after exiting
  `case` loses the pattern equality `rest = (tail_of history)`, causing an
  unbound SMT symbol error. Lowering recursive call arguments *eagerly while
  pattern bindings are live on `pat_binds`* captures `(tail_of history)` cleanly.
. *Real weak-specification defect caught in `Verisim.Spec.drift_of/2`.*
  The initial reference example specified `@post spec(result <= 10_000)` without
  `result >= 0`. It passed `V1`, `V2` (falsified by `10_001`), and `VC-POST`
  (207 Alethe steps `QED`), *yet Stage 9's `BoundaryShift` mutant (`-999_999`)
  survived*, dropping the score to `88.89% < 95.00%` and halting with `Q-603`
  (exit `5`). Tightening the contract to `@post spec(result >= 0 and result <= 10_000)`
  killed 9/9 proof-relevant mutants (`100.00%`, 285 Alethe steps `QED`).
. *ELF Build-ID non-determinism vs load-time NIF hash verification (`Q-303`).*
  Re-running `zig build-lib` without `-fstrip` embeds distinct metadata on
  rebuilds, breaking `binary_sha256` receipt pins; conversely, unconditionally
  rebuilding `.so` during `verify` would overwrite a tampered `.so` before hash
  comparison. Compiling with `-fstrip -O ReleaseSafe` produces bit-identical
  shared objects (`sha256 = 7a50a320...`), and `verify` checks an existing `.so`
  in place without overwriting it unless `--update-receipt` is explicitly passed.

== Concrete implementation roadmap from `v0.1.0-alpha` to `v1.0.0`

=== Milestone M1: BEAM Bytecode & Compiler Tracer Seal (Phase 1 completion)

* *Goal:* Run Quintessence automatically during `mix compile` with zero gap
  between parsed source and loaded `.beam` chunks.
* *Tasks:*
  . Wire `tracers: [Quintessence.Tracer]` into host Mix projects and serialize
    expanded quoted expressions directly from `@after_compile` callbacks into
    `qir/v1` JSON.
  . Inspect compiled `.beam` `ImpT` (imports) and `LitT` chunks in Elixir to
    reject hidden macro injections (`Q-101`--`Q-105`) even in third-party macros.
  . Enforce double-compile SHA-256 identity inside `bwrap --unshare-net` so
    macros reading wall clocks or network state fail closed.
* *Exit gate:* Every fixture in `tests/quintessence/run_suite.sh` fails at
  `mix compile` time with identical `Q-1xx` codes.

=== Milestone M2: Idris2 QTT `qir/v1` Checker & Why3/Dedukti Bridge (Phase 2)

* *Goal:* Replace ad-hoc IR assumptions with typechecked `%default total`
  Idris2 elaboration and standalone `dkcheck` proof checking.
* *Tasks:*
  . Compile `src/interface/Abi/Qir.idr` into a small Idris2 validator executable
    that parses `qir.v1.json`, constructs well-typed `ValidNifSchedule` and
    `WellTypedKCut` indices, and rejects ill-indexed IR before solver dispatch.
  . Implement the Alethe-to-Dedukti reconstruction pass (`alethe2dk`) for the
     propositional resolution + congruence + Farkas linear arithmetic fragment
    (`la_generic`), eliminating remaining `rewrite_holes` reported in
    `warrant.json` or marking un-reconstructed steps explicitly.
* *Exit gate:* `warrant.json` records `rewrite_holes == 0` and passes `dkcheck`
  for all 12 `Verisim` obligations.

=== Milestone M3: Live Apalache & `occupancy-types` Integration (Phase 3)

* *Goal:* Cross-check native unrolled SMT BMC against `apalache-mc` over the
  emitted TLA+ modules and integrate upstream `occupancy-types` R2--R3 HWM algebra.
* *Tasks:*
  . Add `apalache-mc check --inv=MailboxBound --inv=NoUnwarrantedRemoteClaim --inv=EpochConsistent --length=12`
    execution to `layer_b.zig` whenever `apalache-mc` is present on `PATH`,
    parsing `counterexample1.tla` into Elixir source traces.
  . Extend GenServer protocol extraction from static `@choreography` attributes
    to check that every `handle_call` / `handle_cast` / `handle_info` body
    conforms structurally to the declared role projection (session-type
    projection check).
  . Import pinned `occupancy-types` HWM bounds once upstream R2--R3 lands.
* *Exit gate:* Planted body/Face mismatch (e.g. `@choreography` declares `:call`
  while handler performs an unrecorded `GenServer.cast`) fails with `Q-401`.

=== Milestone M4: `ZigProve` AIR Extractor & Rustler Linear Resource Audit (Phase 4)

* *Goal:* Upgrade Layer C from syntax-guided safety/WCET checks to compiler-IR
  (`Zig AIR`) machine proofs and Rustler `ResourceArc<T>` linear ownership.
* *Tasks:*
  . Extract CFG and basic-block instruction counts from `zig build-obj -femit-llvm-ir`
    to compute exact cycle/instruction polynomials per target microarchitecture,
    emitting Lean 4 `tropical-types` proof scripts checked by `lean`.
  . Add a Rust syn/hir lint pass for `#[rustler::nif]` wrappers verifying that
    every NIF > `threshold_us` carries `#[nif(schedule = "DirtyCpu")]` and never
    stores `Env<'a>` or `Term<'a>` past return (`C9`, `C11`).
* *Exit gate:* Mismatched Rustler schedule vs Zig `MaxPlus` bound fails CI with
  `Q-305`; `.lean` `MaxPlus` theorem compiles with zero `sorry`.

=== Milestone M5: ECHIDNA Batch Level-5 Service & Production Hardening (Phases 5--6)

* *Goal:* Promote local `TrustLevel 4` Warrants into signed `TrustLevel 5`
  `COMPLETE` Receipts checked independently by both Rocq (`coqc`) and Lean 4.
* *Tasks:*
  . Implement the ECHIDNA gRPC client in `engine.zig` submitting `qir.v1.json`,
    `quintessence_obligations.v`, `QuintessenceObligations.lean`, and Alethe
    certificates to the batch farm, verifying Ed25519 signatures on returned
    `quintessence.receipt/v1` artifacts.
  . Add persistent content-addressed proof caching keyed on per-obligation
    `smt_sha256` so incremental edits re-verify in `< 200 ms`.
  . Publish SARIF 2.1.0 annotations (`--format sarif`) directly into GitHub Code
    Scanning on pull requests.
* *Exit gate:* `quintessence verify examples/quintessence --strict --require-level-5`
  exits `0` with `TrustLevel = 5`, `axioms = []`, and Ed25519 signature verified.
