= Architecture decision records

An ADR records one decision, the context that forced it, and what it costs. The
number is permanent: a reversed decision is superseded, not renumbered. Number
upwards from the highest file in this directory.

Start from link:0000-template.adoc[0000-template.adoc]. Copy it to the next free
number, fill the status (`Proposed`, then `Accepted` or `Rejected`), and link the
documents it changes. An ADR that claims a proof result must name the checker and
the pinned revision, for the same reason the architecture document does: a
decision resting on a library is only as strong as that library's proof status.
